# Games
This repository contains the collection of games I'm developing as a part of my journey in Engineering and Problem Solving. 

The goal is not only to build playable games, but to strengthen core concepts in programming, algorithms, graphics & many other things.  

Each project in this repository focuses on:  
1. Clean and modular code structure
2. Efficient memory and logic management
3. Object-Oriented Design principles
4. Optimization techniques where applicable
5. Scalable and maintainable architecture

The games range from fundamental logic-based implementations to more interactive graphical applications. 

I shall develop gameplay mechanics as I progress. Apart from the development of new and independent games, special emphasis is placed on:  
1. Collision detection and event handling
2. Game loop design  State management
3. Performance considerations
4. Debugging and testing strategies

This repository serves as both a learning archive and a practical demonstration of problem-solving ability. Every project reflects incremental improvement in design thinking, code efficiency and system understanding. Future updates will include enhancements such as 
1. Improved UI/UX
2. Advanced Algorithms
3. Multiplayer Logic (where applicable)
4. Performance Optimization.

The objective is continuous improvement by building projects that are technically sound, well-structured, and reflective of disciplined engineering practice.
